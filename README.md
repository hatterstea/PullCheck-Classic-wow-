# PullCheck

PullCheck is a lightweight World of Warcraft Classic addon that displays a customizable checklist when a ready check is performed.

It is designed for pre-pull reminders such as Soulstone, Ritual of Souls, food buffs, weapon oil, flask, pet, focus target, or any other raid preparation step.

## Features

- Shows a clickable checklist when a ready check is performed
- Supports multiple custom profiles
- Lets you add and delete checklist items in-game
- Automatically hides when combat starts
- Scrollable checklist item list in the config panel
- Lightweight and event-based; no constant scanning or combat log processing

## Commands

`/pullcheck`  
Opens the configuration panel.

`/pullcheck config`  
Opens the configuration panel.

`/pullcheck show`  
Manually previews the active checklist.

`/pullcheck help`  
Displays available commands.

## Installation

Extract the `PullCheck` folder into:

`World of Warcraft/_anniversary_/Interface/AddOns/`

Then restart the game or type `/reload`.

## Notes

PullCheck does not automatically check whether buffs or cooldowns are active. It is a manual checklist tool intended to make pre-pull routines harder to forget.
